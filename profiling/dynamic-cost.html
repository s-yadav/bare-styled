Dynamic style cost: CSS variable vs per-variant class

Renders N nodes in a flex-wrap container and, for F frames, gives every node a new value of the chosen property, then forces a full style + layout flush and times it. Two models: CSS variable (one static rule, per-node inline custom property — just-styled) vs per-variant class (a fresh class + insertRule per distinct value, cached and reused — styled-components).

Two things to sweep: (1) pick a layout property (width/padding) so the flush includes reflow, not just paint; (2) raise distinct values (K). Low K is per-variant's best case (rules created once, then cheap class swaps); as K approaches N×F every update needs a new rule, so per-variant's rule count and cost climb while the variable model stays flat at one rule.
