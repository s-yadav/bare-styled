Dynamic style cost: CSS variable vs per-variant class

Both scenarios render N nodes and, for F frames, change every node's color, then force a style+layout flush and time it. This isolates the exact difference between the two engines' dynamic model: styled-components mints a new class + insertRule per unique value (stylesheet churn → broad style invalidation); the CSS-variable approach keeps one static rule and updates an inline custom property (element-scoped invalidation, no stylesheet mutation).
